# Karing iPhone: RU direct + Hysteria2 global test

Цель: проверить Karing на iPhone в режиме, где российские домены/IP идут напрямую через текущий Wi-Fi или мобильную сеть, а весь остальной трафик идет через Hysteria2 на зарубежный VPS.

## Новый профиль

Файл для импорта:

```text
D:\AI\airoom-hermes-vds-native-codex-kit\vpn-client-configs\karing-singbox-ru-direct-global-hysteria2.json
```

Что внутри:

- Hysteria2 outbound остается основным маршрутом для зарубежного трафика.
- RU domain/ruleset маршруты идут в `direct`.
- RU DNS идет в `direct`.
- Старый резервный SOCKS5 не используется.
- Порт `50101/tcp` не нужен и не открывается.

## Как импортировать в Karing

1. Передать JSON-файл на iPhone приватным способом.
2. Открыть Karing.
3. Импортировать профиль как sing-box/custom config, если Karing предложит тип импорта.
4. Включить импортированный профиль.
5. Разрешить iOS добавить или обновить VPN-конфигурацию.

Если Karing не принимает JSON как профиль, не чинить правила вручную сразу. Сначала зафиксировать точный текст ошибки или экран, где импорт ломается.

## Что должно работать

Через VPN/Hysteria2:

- Telegram;
- Instagram;
- ChatGPT/OpenAI;
- зарубежные сайты в браузере;
- `https://ifconfig.me` должен показывать IP VPS.

Напрямую:

- `.ru`, `.su`, `.рф`;
- Yandex;
- Avito;
- Ozon;
- Госуслуги;
- банки;
- VK/Mail;
- российские IP из подключенных ruleset.

## Порядок проверки

1. Подключить профиль в Karing.
2. Открыть `https://ifconfig.me`.
   - Ожидаемо: показывает IP VPS.
3. Открыть `https://ya.ru/internet`.
   - Ожидаемо: российский маршрут, не VPS.
4. Проверить приложения:
   - Telegram должен работать через VPN.
   - ChatGPT должен работать через VPN.
   - Avito должен открываться напрямую.
   - Госуслуги или банк не должны ругаться на зарубежный IP.
5. Повторить на Wi-Fi и мобильной сети, если первый тест выглядит успешно.

## Как понять, что Karing не справился

Karing не подходит для этой схемы, если:

- профиль импортируется, но российские приложения все равно видят IP VPS;
- браузерные `.ru` работают напрямую, а приложения Avito/банк/Госуслуги продолжают идти через VPS;
- ruleset не загружаются или Karing падает/зависает на iOS;
- нельзя включить профиль после импорта.

В этом случае следующий практичный шаг: тестировать Streisand или Shadowrocket. Shadowrocket вероятно сильнее для iOS split, но платный.
